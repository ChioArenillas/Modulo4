# Films Data Base

## 🧩 Description

Films Data Base is a web application that allows users to browse information about movies. The app fetches data from an external API to display real film titles, posters, and related details dynamically.

The project focuses on integrating external APIs, handling asynchronous data, and providing a clean and responsive interface for users to explore movie data.

## 🚀 Live Demo

https://films-data-base.vercel.app/

## 🚀 Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* External movie data API
* Vercel (deployment)

## 🎯 Features

* Fetch real movie data from an external API
* Display film titles, posters, and details
* Search functionality for finding movies
* Dynamic rendering of UI based on API responses
* Responsive and interactive user interface

## 🧠 Key Concepts

* Working with external APIs
* Asynchronous JavaScript (fetch / async-await)
* DOM manipulation
* Event handling
* Separation of structure, style, and logic
